## Ghi chú cho script-gen (HITL #2, 2026-11-25)
1. **Locator** (theo thứ tự `CLAUDE.md`; qa-reviewer kiểm 2/2 × `standard_user`, `problem_user`, `error_user`):
   - Nút: `getByRole('button', { name: 'Continue' | 'Cancel' | 'Finish' | 'Back Home' | 'Generate PDF order', exact: true })` (mỗi tên 1 phần tử).
   - Ô nhập: `getByLabel('First Name' | 'Last Name' | 'Zip/Postal Code', { exact: true })` (có `aria-label`); **phải** `exact: true` vì `getByLabel('Name')` khớp 2 ô. Hoặc `getByPlaceholder`.
   - Tên sản phẩm ở Tổng quan: thẻ `a role=button href=#`, tên truy cập `View details for <tên>` (`getByRole('link')` = 0): dùng `getByTestId('item-<id>-title-link')` (hoặc `getByRole('button', { name: 'View details for <tên>' })`).
   - Link giỏ: thẻ `a` không `href`, `role=button` (`getByRole('link', { name: /Cart/ })` = 0, `getByRole('button', { name: /^Cart/ })` = 1). **Số giỏ** đọc `getByTestId('shopping-cart-badge')`, **không** phân tích chữ `aria-label` "Cart, 2 items" (accessibility ngoài phạm vi, TVP-050: không assert nội dung `aria-label`).
   - Tiêu đề Hoàn tất: `getByRole('heading', { name: 'Thank you for your order!' })` hoặc `getByTestId('complete-header')`.
2. **Chốt chặn BUG-26** (quyết định 3): trong TC bug một mục đích, chốt chặn (thấy nút `Finish` sau khi mở thẳng `/checkout-step-two.html`) chạy **trước** `test.fail(true, 'BUG-xx …')`; gọi `test.fail()` trong thân test sau khi chốt chặn qua. Nếu khai báo `test.fail()` trước, assertion chốt chặn đỏ cũng thành "fail như mong đợi" (bài học L4).
3. **Quét giỏ** (quyết định 4): 120 giỏ, 1 context, `test.setTimeout(180_000)`, không tăng `retries`, `test.info().annotations.push({ type: 'sweep', description: 'đã quét n/120 giỏ' })`.
4. **Bố cục** (quyết định 5): hằng số sai số 5 px dùng chung, mốc `standard_user` cùng lần chạy, chờ `document.fonts.ready` và ảnh tải xong; không dùng class `visual_failure`.
5. **Oracle "tô đỏ"** (review-test-impl A1): class `error` so theo token + số `.error_icon`; **không** dùng `input_error` (luôn có).
6. **Expected phủ định**: chờ trạng thái sai tối đa 5 giây (vd `complete-header`, ô `firstName`), không xuất hiện = đúng; hoặc chờ phần tử riêng của trang đúng.
